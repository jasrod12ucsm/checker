# Portada, resumen y abstract

## Título

Centinela C++: servicio web de revisión automática de *pull requests* que detecta usos de iteradores, referencias y punteros invalidados mediante un checker para Clang Static Analyzer

## Resumen

En C++, usar un iterador, una referencia o un puntero a un elemento de un contenedor después de una operación que lo invalidó produce comportamiento indefinido, y este error puede pasar a producción porque depende de partes del código que no siempre forman parte del cambio que se revisa. Este proyecto desarrolló Centinela C++, un servicio web con registro, autenticación y roles que se conecta a los repositorios de GitHub de un equipo, recibe cada *pull request* mediante un *webhook* firmado, analiza los archivos que cambiaron, comenta cada uso inválido en su línea con la ruta que lo explica y bloquea el *merge* cuando el equipo lo pide. El análisis lo realiza `ucsm.ContainerInvalidation`, un checker para Clang Static Analyzer (LLVM 21) que aplica las reglas de invalidación de la norma C++17, escritas como datos con su cláusula, para diez contenedores. El checker se evaluó con un banco de 750 casos etiquetados desde la norma y validados en 852 ejecuciones con instrumentación dinámica, sin contradicciones: la configuración de referencia detectó 80 de 342 usos inválidos (exhaustividad de 23,4 %) y ninguno sobre referencias o punteros; con el checker se detectaron los 342, sin falsas alarmas en 306 casos seguros y con un sobrecosto mediano de tiempo de 0,3 %. En cuatro proyectos reales (781 unidades de compilación) no se produjeron caídas, se detectaron los 8 defectos sembrados y no se emitieron avisos en los 2 usos correctos sembrados. El servicio se construyó con TypeScript, Fastify y SQLite en una arquitectura de puertos y adaptadores, con un panel web en React y 279 pruebas automáticas; soporta 870 consultas por segundo sin caerse con 1 600 conexiones simultáneas, aprobó 41 de 41 pruebas de seguridad y no tiene violaciones de WCAG 2.1 AA, y se despliega con Docker.

**Palabras clave:** servicio web, revisión de código, *pull request*, análisis estático, Clang Static Analyzer, invalidación de iteradores.

## Abstract

In C++, using an iterator, reference, or pointer to a container element after an operation has invalidated it is undefined behavior, and this error can reach production because it depends on parts of the code that are not always included in the change under review. This project developed Centinela C++, a web service with registration, authentication, and roles that connects to a team's GitHub repositories, receives every pull request through a signed webhook, analyzes the changed files, comments on each invalid use at its line together with the path that explains it, and blocks the merge when the team requires it. The analysis is performed by `ucsm.ContainerInvalidation`, a Clang Static Analyzer checker (LLVM 21) that applies the C++17 invalidation rules, encoded as data with their clauses, to ten containers. The checker was evaluated on a benchmark of 750 cases labeled from the standard and validated by 852 dynamically instrumented runs with no contradictions: the reference configuration detected 80 of 342 invalid uses (23.4% recall) and none on references or pointers, whereas the checker detected all 342, with no false alarms on 306 safe cases and a median time overhead of 0.3%. On four real-world projects (781 translation units) it did not crash, detected all 8 seeded defects, and raised no warnings on the 2 seeded correct uses. The service was built with TypeScript, Fastify, and SQLite in a ports-and-adapters architecture, has a React web panel, is covered by 279 automated tests, sustains 870 requests per second without failing under 1,600 concurrent connections, passed 41 of 41 security checks, has no WCAG 2.1 AA violations, and is deployed with Docker.

**Keywords:** web service, code review, pull request, static analysis, Clang Static Analyzer, iterator invalidation.
